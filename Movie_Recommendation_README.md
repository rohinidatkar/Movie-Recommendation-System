# 🎬 Movie Recommendation System

A hybrid movie recommendation engine built using collaborative filtering, content-based filtering, and popularity-based models.

## 📌 Problem Statement
Help users discover movies they might enjoy by analyzing historical preferences and generating personalized suggestions.

## 🛠️ Tools & Technologies
- Python, pandas, scikit-learn
- Cosine similarity, TF-IDF
- Jupyter Notebook

## 📈 Features
- Popularity-based recommendations
- Content-based filtering using genres and overviews
- Collaborative filtering for personalized suggestions

## 💡 Key Insights
- Combined models enhance recommendation accuracy
- Scalable to larger movie datasets

## 📂 Repository Structure
- `recommendation_engine.ipynb`: Main notebook
- `data/`: Input datasets

## 🚀 How to Run
Open the notebook in Jupyter and follow the cell-by-cell instructions.
